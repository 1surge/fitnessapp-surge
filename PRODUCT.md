# Surge Fitness

## Platform
web — single HTML file, no build step

## Stack
Vanilla HTML/CSS/JavaScript and `data.js`. On-device storage by default, with an optional user-chosen cloud folder (Drive/OneDrive/iCloud via the File System Access API where the browser allows it, export/import everywhere else). No accounts, no app-run server.

## Audience and scene
Public training log for anyone who trains, used on a phone in a noisy gym. Works anonymously with no age framing or identity collection.

## Jobs and content
A new user can start a useful session without entering a name, body details or personalization. Today's plan, exercise demos, fast weight/reps logging, pause/resume/skip/substitute/cancel, history, export. Five weekday visits: three full-body strength sessions and two recovery sessions.

## Safety and psychology
Technique, gradual progression, and a coach's eyes on new lifts before load. No maximal-lift encouragement, guilt, body comparison, calorie targets or restrictive eating. Reduce choice overload and make the next action clear. Recovery counts as training.

## Brand commitments
Surge Fitness brand. Mobile usability, accessibility and truthful functionality win over effects.

## Constraints
Free hosting only (GitHub Pages). Ship `index.html` as the live build. Do not fabricate metrics or integration status. Verify with real browser screenshots before presenting.
